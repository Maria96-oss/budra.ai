Единственный источник правды по проекту. Обновляется при каждом изменении решений.

## Что это

Сайт-портфолио Марии Будревич. Задача: показать клиенту-селлеру живой пример работы
и получить заявку. Продукт — сайты для селлеров маркетплейсов и малого бизнеса,

## Стек

Статика без сборщика: один `index.html`, всё внутри. По правилу скилла
«1 страница, 3D-объект в герое → статика, без сборщика».

| Библиотека | Версия | Зачем |
|---|---|---|
| Three.js | r128, UMD с cdnjs | 3D-сцена в герое |
| GSAP + ScrollTrigger | 3.13.0, UMD | появление блоков при скролле |
| Lenis | 1.3.11, UMD | плавный скролл |

**Почему r128 UMD, а не 0.185 ESM.** Мария открывает сайт двойным кликом с рабочего
стола, по `file://`. ES-модули и importmap там блокируются браузером, сайт бы просто
не открылся. UMD-сборки работают и локально, и на хостинге. После деплоя на
GitHub Pages можно перейти на 0.185 через importmap — тогда ограничение снимается.

## Визуальное направление

Референс задан Марией: тёмный графит, чёрно-белая графика с ярко-розовым акцентом,
рукописный розовый шрифт поверх плотного капса.

- Фон: `#26262D`, полупрозрачные стеклянные панели (`backdrop-filter: blur(22px)`)
- Акцент: розовый `#FF4FA8`, вторичный фиолетовый `#8B6BFF`
- Текст: `#EFEFF3`, приглушённый `#A9A9B6`
- Шрифты: Oswald 600–700 (заголовки капсом), Yellowtail (розовые рукописные вставки),
  Manrope 300–700 (текст)

## 3D-сцена

Тоннель из светящихся колец, уходящий в глубину: ощущение, что мы внутри системы.
Камера летит вперёд по мере прокрутки. Кнопка «Посмотреть работу» делает нырок
глубже и выводит к кейсу. Кот Маши — вырезанное фото поверх сцены, реагирует
на курсор.

Соблюдено по чек-листу скилла:

- деградация: `shouldRender3D()` проверяет WebGL, число ядер и режим экономии трафика;
  без 3D остаётся градиентный фон, вёрстка не ломается;
- мобильные: меньше колец (10 против 18), ниже сегментация геометрии,
  `pixelRatio` 1.5, antialias выключен;
- `prefers-reduced-motion`: анимации сцены и появление блоков отключаются;
- `destroy()` с `dispose()` всех геометрий, материалов и рендерера;
- скролл не перехватывается: Lenis только сглаживает, страница листается свободно;
- ни одной запиненной секции.
